BlockMCP Web Bridge

Conecte o Blockbench no navegador a clientes MCP por meio de um servidor remoto autenticado.

1. Instale o plugin no Blockbench Web

Abra web.blockbench.net, acesse Arquivo → Plugins → Carregar Plugin de URL e use:

URL_DO_SERVIDOR/blockmcp_web.js

2. Conecte

No Blockbench, vá a Ferramentas → Conectar BlockMCP Web. Preencha o endereço HTTPS deste serviço e a chave BLOCKMCP_API_KEY configurada no Render.

3. Configure um cliente MCP

URL do endpoint: URL_DO_SERVIDOR/mcp

Envie o cabeçalho HTTP Authorization: Bearer SUA_CHAVE. Mantenha a aba do Blockbench aberta e conectada.

Ferramentas disponíveis

Informações do projeto, listagem de cubos/grupos/texturas/animações, criação de cubos e grupos, edição e exclusão de cubos com Undo.

Limitação: é uma versão web inicial. O plugin desktop original oferece mais ferramentas. Não há execução remota arbitrária de JavaScript neste serviço.
